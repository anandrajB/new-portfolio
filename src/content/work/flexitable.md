##### **Flexitable – No-Code Workflow & Data Management Platform**

Developed and maintained a scalable no-code platform that enables organizations to manage business processes through customizable tables, forms, workflows, approvals, and automation. Built backend services for dynamic data modeling, role-based access control, real-time collaboration, workflow execution, and API integrations. Designed reusable architectures to support configurable business applications without requiring code changes, improving development efficiency and customer onboarding.

**Key Contributions**

* Designed and developed REST APIs using Django and Django REST Framework.
* Implemented dynamic table architecture supporting custom fields, relationships, filtering, sorting, and data validation.
* Built configurable workflow and approval systems using Finite State Machine (FSM) concepts.
* Developed role-based access control (RBAC) and workspace-level permissions.
* Optimized database performance through query tuning, caching, and asynchronous processing.
* Implemented real-time notifications and activity tracking using WebSockets.
* Integrated third-party services for authentication, email delivery, and cloud storage.
* Developed reusable backend components and abstractions to accelerate feature development.
* Created audit logging, middleware, and security mechanisms for enterprise-grade data management.
