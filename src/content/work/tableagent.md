TF Masters is a web and mobile learning platform focused on Trade Finance education, industry news, challenges, quizzes, expert insights, job opportunities, and performance tracking for finance professionals. The platform delivers personalized learning experiences through articles, assessments, rewards, analytics, and real-time content updates.


* Developed REST APIs using Django and Django REST Framework.
* Built article, news, and knowledge management modules for content publishing.
* Developed quiz, challenge, leaderboard, streak, and reward systems to improve user engagement.
* Implemented event-driven architecture using Kafka for notifications, analytics, and asynchronous processing.
* Integrated Google Analytics for user behavior tracking, engagement monitoring, and product insights.
* Built real-time notification and activity systems.
* Developed role-based admin dashboards for content and user management.
* Optimized database queries, caching strategies, and API performance for large-scale content delivery.
* Implemented bookmark, search, recommendation, and personalized learning features.
* Built reporting and progress tracking modules for learning performance analysis.
* Collaborated across product, design, and business teams to deliver new learning experiences.
